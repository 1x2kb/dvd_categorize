# Categorizer Utilities Module

Miscellaneous utility functions for the DVD Categorizer application.

## Overview

This crate contains shared utility functions that don't fit into other specific modules. Currently minimal, but provides a place for common helper functions used across the workspace.

## Usage

```rust
use categorizer_utilities::*;
```

## Dependencies

Minimal dependencies - designed to be lightweight and reusable.

## Future Additions

This module can be extended with:
- String manipulation utilities
- Date/time formatting helpers
- Common validation functions
- File I/O utilities
- Configuration helpers
